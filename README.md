# Smart Expense Tracker with Python & LLMs

A Python-based financial tracker that automates expense categorization using OpenAI's GPT-4o-mini and visualizes spending trends using Matplotlib.

## Features
* Data cleaning and row filtering using pandas.
* Automated expense categorization using OpenAI API (`gpt-4o-mini`).
* Data visualization with expense pie charts and bar charts via Matplotlib.

## Tech Stack
* Python
* pandas
* OpenAI API (`gpt-4o-mini`)
* Matplotlib
